  <h1>📝 Classificação de Risco de Burnout Estudantil - SVM</h1>

  <p>Atividade acadêmica desenvolvida em Python utilizando a base de dados sobre o impacto da Inteligência Artificial Generativa nos estudantes. O projeto envolve pré-processamento, validação cruzada 5-fold e exploração de hiperparâmetros (parâmetro C e diferentes Kernels) utilizando o algoritmo Support Vector Machine (SVM).</p>

  <h1>🛠️ Tecnologias e Ferramentas</h1>
  🐍 Python &nbsp;|&nbsp; 🐼 Pandas | NumPy &nbsp;|&nbsp; ⚙️ Scikit-learn (SVC, StandardScaler, StratifiedKFold) &nbsp;|&nbsp; 📊 SVM (GridSearch de C e Kernels) &nbsp;|&nbsp; 📉 Matplotlib</p>
