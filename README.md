# 📝 Classificação de Risco de Burnout Estudantil

Atividade acadêmica desenvolvida em Python utilizando uma base de dados sobre o impacto da Inteligência Artificial Generativa na vida acadêmica dos estudantes. O projeto envolve pré-processamento dos dados e comparação dos algoritmos K-Nearest Neighbors (KNN) e Gaussian Naive Bayes para classificação do nível de risco de burnout.

## 🛠️ Tecnologias e Ferramentas

🐍 Python
🐼 Pandas | NumPy
⚙️ Scikit-learn
📊 KNN | Gaussian Naive Bayes
🧪 Cross-Validation | MinMaxScaler | Label Encoding
