# 🌳 Comparação de Algoritmos de Machine Learning

Atividade acadêmica desenvolvida em Python utilizando uma base de dados sobre o impacto da Inteligência Artificial Generativa na vida acadêmica dos estudantes.

O projeto compara quatro algoritmos de classificação: Decision Tree, Random Forest, K-Nearest Neighbors (KNN) e Gaussian Naive Bayes. A avaliação utiliza validação cruzada 5-fold e acurácia para identificar o modelo com melhor desempenho na classificação do risco de burnout estudantil.

## 🛠️ Tecnologias e Ferramentas

🐍 Python
🐼 Pandas | NumPy
⚙️ Scikit-learn
🌳 Decision Tree | Random Forest
📊 KNN | Gaussian Naive Bayes
🧪 Cross-Validation | MinMaxScaler | Label Encoding
