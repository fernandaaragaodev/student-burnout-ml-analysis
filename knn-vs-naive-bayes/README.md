# 📊 Comparação entre KNN e Naive Bayes

Atividade acadêmica desenvolvida em Python utilizando uma base de dados sobre o impacto da Inteligência Artificial Generativa na vida acadêmica dos estudantes.

O projeto realiza o pré-processamento dos dados e compara os algoritmos K-Nearest Neighbors (KNN) e Gaussian Naive Bayes para classificação do nível de risco de burnout estudantil, utilizando validação cruzada 5-fold.

## 🛠️ Tecnologias e Ferramentas

🐍 Python
🐼 Pandas | NumPy
⚙️ Scikit-learn
📊 KNN | Gaussian Naive Bayes
🧪 Cross-Validation | MinMaxScaler | Label Encoding
