# 🧠 Classificação com Rede Neural MLP

Atividade acadêmica desenvolvida em Python utilizando uma base de dados sobre o impacto da Inteligência Artificial Generativa na vida acadêmica dos estudantes.

O projeto utiliza uma rede neural Multilayer Perceptron (MLP) para classificação do nível de risco de burnout estudantil. Foram aplicados pré-processamento dos dados, normalização, divisão entre treino e teste e otimização de hiperparâmetros com GridSearchCV e validação cruzada 5-fold.

## 🛠️ Tecnologias e Ferramentas

🐍 Python
🐼 Pandas
⚙️ Scikit-learn
🧠 MLPClassifier | Neural Networks
🔍 GridSearchCV | Hyperparameter Tuning
🧪 StandardScaler | Train-Test Split | Cross-Validation
